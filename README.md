## 🏆 Projetos em Destaque

### 🎯 Sistema de Gerenciamento de Serviços
**A aplicação que transformou uma planilha Excel em um app web profissional!**

Uma solução completa desenvolvida para técnicos autônomos que prestam serviços de instalação, manutenção e reparo de redes. Antes usavam Excel, agora têm um sistema web robusto e intuitivo.

**Funcionalidades principais:**
- ✅ Autenticação segura com **Supabase Auth**
- 📊 Dashboard inteligente com KPIs (OS do mês, faturamento, OS hoje, OS abertas)
- 🏢 CRUD completo de empresas contratantes
- 📋 Ciclo completo de Ordens de Serviço: Aberta → Concluída → Faturada
- 📸 Captura de fotos de evidência com upload para Supabase Storage
- 🗺️ Captura de GPS via navegador
- 📈 Relatórios avançados com filtros e exportação PDF/XLSX
- 🌓 Dark/Light Mode
- 📱 Design responsivo (mobile-first)

**Stack:** React | Supabase | Vercel | PostgreSQL

*Este projeto me trouxe muita experiência real e confiança como desenvolvedor!*
